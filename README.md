# 水利具身智能协同指挥中心

这是一个面向水利巡检业务的空—天—地—水协同指挥系统。三套设计方案保留为三个工作台：

- **态势总览**：水库主图、四类设备定位、设备选择、告警入口与任务入口。
- **事件管理**：热成像证据、处置建议、人工确认与协同任务下达。
- **协同编排**：设备筛选、时序任务编排、计划发布、模拟演练与启动状态。

系统包含本地实时网关：设备遥测通过 SSE 推送到页面，统一接收无人机、无人船、轮式机器人与机器狗的状态、告警、电子围栏和任务申请。正式运营入口默认采用 **现场集成模式**：未接入设备时显示空状态，不会生成样例设备、告警或任务结果。

从首次激活、设备接入到日常值守的总手册见 [正式系统全流程操作手册](docs/正式系统全流程操作手册.md)。

完整的日常操作、遥测注入与封闭场地测试步骤见 [项目使用与线下测试指南](docs/项目使用与线下测试指南.md)。

按无人机、无人船、轮式机器人和机器狗分别接入的实施步骤见 [设备接入实施指南](docs/设备接入实施指南.md)。

## 正式运行（推荐）

首次在这台电脑部署时，双击：

`首次部署正式系统.cmd`

之后日常使用只需双击：

`启动正式系统.cmd`

系统会在默认浏览器中打开 <http://127.0.0.1:8080>，并以 `integration` 模式启动独立网关（端口 `8878`）。正式入口不会占用开发/演练使用的 `5173` 和 `8787` 端口。

## 开发与演练运行

```powershell
cd E:\Codex\water-embodied-command-center
npm install
npm run dev:realtime
```

打开 <http://127.0.0.1:5173>。该命令只用于开发和封闭场地演练，会同时启动前端和演练网关；不应作为值守终端的日常启动方式。

## 真实设备接入

- 统一遥测和告警接口、SSE 事件流、指令接口与安全状态机见 [设备网关契约](docs/device-gateway-contract.md)。
- 适配器连接参数样例见 [device-adapters.example.json](config/device-adapters.example.json)：无人机使用 MAVLink 2，水面设备使用 MQTT 5，轮式机器人和机器狗使用 ROS 2。
- 现场部署时，将厂商 SDK、飞控或机器人节点接到专网内的边缘适配器；适配器把数据转换为统一接口。前端始终只连网关，不能直接连飞控、电机或机器人控制器。
- `simulation` 仅用于演练；`integration` 可接收真实遥测、保存围栏并提交待审批的任务申请，但拒绝真实控制；当前代码库内的 `live` 请求会被明确拒绝。真实控制只能在部署经过认证的现场边缘执行适配器、操作者认证、围栏同步、急停/失联/低电量校验和设备回执之后，由该适配器实现。

## 发布版地图操作

- “态势总览”主地图为 WebGL 三维工程场景，不是可缩放图片；地形、水域、坝体、闸门、航线、作业区与设备均为独立三维对象。
- 使用 **正射 / 鸟瞰 / 坝体** 切换全域、倾斜航测和坝体细节视角。
- **左键拖动平移**，**右键拖动旋转/俯仰**，滚轮或右上角 `+ / −` 缩放；`复位` 回到全域正射视图，十字准星直达坝体细节。
- 当前 WGS-84 和比例尺读数、地形高程为演练示例。接入真实工程时，网关应提供坐标参考系、DEM/DSM、无人机正射影像、点云或 3D Tiles、影像时间和高程基准；设备位置应由经纬度/投影坐标映射，而不是使用演示的 `x/y` 百分比。

## 电子围栏与传感器

- 点击“电子围栏”后可输入名称和类型（禁入、限高、水面作业），选择“开始在地图点选”，在三维地形上依次点击至少三个边界点；支持撤销、保存与删除。保存后的围栏会直接显示在三维场景中。
- 正式入口会把已保存的围栏持久化到 `data/operator-state.json`，并通过网关事件同步给已打开的运营页面。该文件适合单机值守；多值守终端和正式生产环境应替换为具备权限、审计和备份能力的数据库，并同步到现场安全控制器。
- 点击“传感监测”可按设备切换：无人机显示飞行高度、风速、云台温度；无人船显示 pH、浊度、水温；轮式机器人显示柜体温度、振动、气体；机器狗显示坡面倾角、表面温度、气体。
- 演练网关每两秒推送 `sensors` 字段。生产接入时，边缘适配器应将厂商测点标准化后写入该字段，并在任务执行前把已审核的电子围栏同步到现场安全控制器。

## 演练路径

1. 在“态势总览”点击“溢洪道左侧边坡位移”告警。
2. 在“风险处置”检查红外证据与推荐调度方案。
3. 点击“执行协同任务”，验证任务下达状态与成功提示。
4. 打开“协同编排”，按设备类型筛选，发布计划并点击“启动任务”。
5. 返回“态势总览”，验证协同演练已启动的提示。

## 接入真实设备前的边界

当前版本的界面可接收网关遥测，并在默认模式下只运行模拟任务；**不会向真实无人机、无人船、机器人或机器狗发送控制指令**。生产接入应由经过认证的边缘网关执行低层控制，并至少补齐：

- 设备身份认证、指令签名、操作者权限与全量审计；
- 电子围栏、失联返航、低电量保护、紧急停止等本地安全约束；
- 统一设备状态、视频流、任务、告警和传感器 API；
- 人工二次授权与现场应急预案。

建议优先用一座水库的“无人机 + 无人船 + 机器狗”进行封闭演练，再接入泵闸站轮式机器人和真实告警数据。
