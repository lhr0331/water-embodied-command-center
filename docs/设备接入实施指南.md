# 设备接入实施指南

本文说明如何将无人机、无人船、轮式机器人和机器狗接入水利具身智能协同指挥中心的正式入口。目标是先完成**只读遥测、传感器、告警和视频接入**，再按现场安全流程建设真实控制能力。

> 当前标准版本的正式入口运行在 `http://127.0.0.1:8080`，处于 `integration` 模式。它可以接收设备数据、保存电子围栏和提交待审批任务申请；它不会直接控制真实设备，并且会拒绝浏览器来源的 `live` 控制请求。

## 1. 推荐接入架构

```text
无人机飞控 / 无人船控制器 / ROS 2 机器人节点 / 厂商 SDK
                         │
                         │  MAVLink 2 / MQTT 5 / ROS 2 / 厂商协议
                         ▼
                  现场边缘适配器（工控机）
                         │
                         │  统一 HTTP 遥测、告警、视频网关接口
                         ▼
     本机正式网关 http://127.0.0.1:8878 （仅本机监听）
                         │
                         ▼
        运营页面 http://127.0.0.1:8080 （三维地图与调度）
```

第一阶段请将“正式系统”和各设备的边缘适配器部署在**同一台现场工控机**。适配器向 `127.0.0.1:8878` 上报数据，避免在局域网或公网暴露无鉴权的接入接口。

如果设备协议必须跨电脑传输，应在设备专网内使用厂商 VPN、专用交换机或已认证的消息总线。不要将 `8878` 直接映射到公网；多机部署前必须补充 mTLS、访问控制、审计和反向代理。

## 2. 首次准备

1. 在现场工控机上双击 `首次部署正式系统.cmd`。
2. 以后双击 `启动正式系统.cmd`，确认浏览器打开 `http://127.0.0.1:8080`。
3. 在工控机 PowerShell 检查网关：

```powershell
Invoke-RestMethod http://127.0.0.1:8080/health
```

预期看到：`status: ok`、`mode: integration`、`liveCommandAvailable: false`。

4. 为每一台设备分配固定且唯一的 `deviceId`，例如：

| 设备 | 示例 ID | 连接协议 | 建议的适配器部署位置 |
|---|---|---|---|
| 无人机 | `UAV-D01` | MAVLink 2 / 厂商 SDK | 地面站或机库工控机 |
| 无人船 | `USV-B01` | MQTT 5 / 厂商 SDK | 船坞或水面通信工控机 |
| 轮式机器人 | `UGV-R01` | ROS 2 / 厂商 SDK | 泵站、闸站就地工控机 |
| 机器狗 | `QGV-Q01` | ROS 2 / 厂商 SDK | 堤坝、廊道就地工控机 |

5. 把设备的证书、密钥、Wi-Fi/4G/5G 凭据保存在现场密码库或厂商安全模块中；不要写入网页、前端代码、Markdown 文档或聊天窗口。

## 3. 边缘适配器的工作内容

边缘适配器是设备厂商协议与平台统一协议之间的转换程序。每个适配器必须完成：

1. 连接设备或厂商服务。
2. 读取心跳、位置、电量、作业状态与传感器数据。
3. 为数据加入设备 ID、采集时间、链路质量和质量标记。
4. 将厂商字段转换为本平台的统一 JSON。
5. 每 1–5 秒向本机网关发送一次遥测；异常发生时立即发送告警。
6. 本地检测失联、急停、低电量和电子围栏状态。
7. 写入本地审计日志，并在网络恢复后按顺序补发允许补发的数据。

适配器不应把设备控制端口暴露给浏览器。当前版本只需要实现上报功能；真实控制适配器必须另行经过安全评审。

## 4. 统一遥测上报格式

所有设备向以下地址上报：

```text
POST http://127.0.0.1:8878/api/v1/ingest/telemetry
Content-Type: application/json
```

最小报文如下：

```json
{
  "deviceId": "UAV-D01",
  "type": "drone",
  "label": "无人机 D-01",
  "state": "在线巡检",
  "battery": 78.4,
  "linkQuality": 96,
  "speed": 12.6,
  "location": "主坝东侧",
  "x": "72%",
  "y": "42%",
  "protocol": "mavlink",
  "sensors": {
    "flightAltitude": 121.6,
    "windSpeed": 5.3,
    "cameraTemp": 38.1
  }
}
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---:|---|
| `deviceId` | 是 | 全局唯一设备编号；创建后不要随意更改。 |
| `type` | 建议 | `drone`、`boat`、`rover` 或 `dog`。 |
| `battery` | 建议 | 0–100 的百分比。 |
| `linkQuality` | 建议 | 0–100 的链路质量。 |
| `speed` | 建议 | 米/秒。 |
| `location` | 建议 | 便于值守人员识别的位置文字。 |
| `x`、`y` | 当前需要 | 当前三维工程底图使用的定位百分比，例如 `"72%"`。真实 GIS 底图上线后应改由坐标转换服务生成。 |
| `protocol` | 建议 | 如 `mavlink`、`mqtt`、`ros2` 或厂商协议名称。 |
| `sensors` | 建议 | 按设备类型标准化的传感器对象。 |

适配器还应在自身数据库保留原始经纬度、高程、航向、采集时间、坐标参考系、原始帧 ID 和设备证书主体。当前三维底图尚未加载实际水利工程的 GIS/DEM 数据，因此请先使用已校准的 `x/y` 映射；不要将示例坐标直接当作真实地理坐标。

## 5. 各类设备的接入步骤

### 5.1 无人机：MAVLink 2 或厂商 SDK

1. 在地面站或机库工控机安装厂商认可的 MAVLink/SDK 桥接程序。
2. 只读订阅心跳、系统状态、电池、GPS/位置、速度、任务状态和云台温度；通信地址和端口以飞控与厂商文档为准。
3. 将飞行高度、风速、云台温度分别归一化为：

```json
"sensors": {
  "flightAltitude": 121.6,
  "windSpeed": 5.3,
  "cameraTemp": 38.1
}
```

4. 每 1–2 秒发送一次统一遥测报文到本机网关。
5. 模拟或停机状态下先验证心跳丢失、电量低于阈值、GPS 无效和围栏接近告警。
6. 在正式页面看到 `UAV-D01`、电量、链路、速度和三项传感器后，完成无人机只读接入验收。

无人机的返航、起降、航线和云台控制仍只能通过经过认证的现场安全控制器执行。

### 5.2 无人船：MQTT 5 或厂商 SDK

1. 在船坞或水面通信工控机部署 MQTT 客户端适配器；Broker 必须位于专网，并为每艘船建立独立身份和 ACL。
2. 订阅船况、水质、测深、GNSS 和电池主题。主题名称按厂商系统配置，例如 `waterworks/usv/<设备ID>/telemetry`。
3. 将水质字段归一化为：

```json
"sensors": {
  "ph": 7.2,
  "turbidity": 18.6,
  "waterTemp": 24.2
}
```

4. 适配器校验消息时间戳、QoS、设备证书和重复序号后，再上报平台。
5. 断开船端通信时，适配器应发送“失联”告警；不得由网页直接发布推进、转向或返航主题。
6. 在正式页面确认 `USV-B01` 的位置、水质传感器和链路质量正常变化。

### 5.3 轮式机器人：ROS 2 或厂商 SDK

1. 在泵站、闸站或厂区就地工控机运行 ROS 2 桥接节点。
2. 订阅位姿、电池、诊断、设备振动、柜体温度、气体检测和急停健康状态。具体话题名因机器人厂商而异，应由厂商提供。
3. 归一化传感器字段：

```json
"sensors": {
  "cabinetTemp": 32.4,
  "vibration": 1.6,
  "gas": 2
}
```

4. 先在机器人静止状态验证位置、急停健康、链路中断和传感器异常上报。
5. 只有本地安全节点可以连接速度控制、导航或机械臂控制话题；网页只能看到状态与提交任务申请。

### 5.4 机器狗：ROS 2 或厂商 SDK

1. 在堤坝边坡、地下廊道的就地工控机运行机器狗 ROS 2/SDK 适配器。
2. 读取位姿、足端状态、电池、坡度、表面温度、气体、网络质量和急停状态。
3. 归一化传感器字段：

```json
"sensors": {
  "slopeAngle": 18.2,
  "surfaceTemp": 29.2,
  "gas": 2
}
```

4. 先完成静态、牵引保护和遥控接管测试，再开展低速巡检。
5. 边缘适配器必须拒绝在急停异常、坡度超限、失联或电量不足时执行动作。

## 6. 告警接入

适配器在检测到异常时发送：

```text
POST http://127.0.0.1:8878/api/v1/ingest/alerts
```

```json
{
  "level": "warning",
  "title": "USV-B01 水质浊度超阈值",
  "place": "库区北侧采样点",
  "confidence": "93%",
  "source": "usv-water-quality-adapter"
}
```

`level` 使用 `warning` 或 `critical`。告警到达后会出现在正式页面右侧，值守人员可确认事件并提交协同任务申请；这不等同于设备已收到执行指令。

## 7. 先用 PowerShell 验证适配器输出

在适配器程序接入前，可在同一台工控机执行以下命令验证网关路径：

```powershell
$body = @{
  deviceId = 'UAV-D01'
  type = 'drone'
  label = '无人机 D-01'
  state = '在线巡检'
  battery = 73.5
  linkQuality = 96
  speed = 12.8
  location = '主坝东侧'
  x = '72%'
  y = '42%'
  protocol = 'mavlink'
  sensors = @{
    flightAltitude = 121.6
    windSpeed = 6.2
    cameraTemp = 38.1
  }
} | ConvertTo-Json -Depth 3

Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8878/api/v1/ingest/telemetry' -ContentType 'application/json' -Body $body
```

成功后刷新正式页面，应出现 `UAV-D01`。这一步通过后，再将 PowerShell 模拟上报替换为实际边缘适配器即可。

## 8. 电子围栏与视频

- 值守人员在网页创建围栏后，网关会将其保存到 `data/operator-state.json`。正式控制适配器必须读取或接收经过审批的围栏版本，并在**设备本地**执行禁入、限高、航行边界和急停校验。
- 现场视频需要独立的视频边缘网关，将 RTSP 或厂商视频流转为经过鉴权的 WebRTC、HLS 或受控 RTSP。浏览器不能直接访问设备相机。
- 在视频网关接入前，正式页面显示“未配置现场视频流”是预期安全状态，不会展示演练图片冒充现场画面。

## 9. 设备接入验收清单

- [ ] 每台设备使用唯一 `deviceId`，并能在正式页面显示。
- [ ] 电量、链路、速度和至少一组传感器在 5 秒内更新。
- [ ] 设备失联、低电量、传感器超阈值能产生可追溯告警。
- [ ] 设备在网页中的位置已用现场地标进行校准。
- [ ] 电子围栏在网页和设备安全控制器中使用相同坐标系、版本号和有效期。
- [ ] 急停、人工接管、失联策略和低电量策略已经过单设备封闭场地验证。
- [ ] 真实控制能力尚未启用，直至完成安全评审、证书、审批和设备回执联调。

## 10. 要完成真实控制接入，还需要提供的资料

请为每个设备类型提供以下非敏感技术资料：设备型号、厂商 SDK/协议版本、遥测字段说明、测试环境地址、ROS 2 话题或 MQTT 主题规范、视频流协议、坐标参考系和安全状态字段。证书、密码、Token 和公网地址不要发送到聊天中。

收到这些资料后，可以分别实现 MAVLink、MQTT、ROS 2 或厂商 SDK 边缘适配器，并在封闭场地完成只读联调、围栏校验、人工审批和设备回执测试。
