# 水利具身智能协同指挥中心：使用与线下测试指南

本文用于系统的日常运营、实验室联调和封闭场地测试。正式入口默认处于“现场集成模式”：网页显示来自网关的真实遥测、告警和围栏，但**不会直接控制无人机、无人船、轮式机器人或机器狗**。

各类设备的接入步骤见 [设备接入实施指南](设备接入实施指南.md)。

首次激活、设备接入、日常值守和异常处理的全流程见 [正式系统全流程操作手册](正式系统全流程操作手册.md)。

## 1. 测试目标与边界

本次线下测试应验证以下闭环：

1. 设备或模拟器向网关上报遥测和传感器数据。
2. 网关通过实时事件流将数据推送到网页。
3. 值守人员在三维地图查看设备、传感器、告警和电子围栏。
4. 值守人员完成告警确认、协同任务编排与模拟下达。
5. 现场边缘适配器在未来接入真实设备前，完成围栏、急停、失联、低电量等本地安全校验。

当前版本可用于 1–4 的演练和集成测试。真实设备的低层控制必须由现场专网内的边缘适配器完成，不允许由浏览器绕过安全控制器直接执行。

## 2. 启动正式运营系统（推荐）

首次在本机部署时，双击项目根目录的：

`首次部署正式系统.cmd`

随后每次使用，双击：

`启动正式系统.cmd`

浏览器会自动打开 <http://127.0.0.1:8080>。右上角显示“集成网关”即表示运营页面与网关相连。该模式使用独立的 `8878` 网关端口，启动后设备数、告警数为 0 是正常状态；只有边缘适配器上报现场数据后，设备与告警才会出现。

可在 PowerShell 中检查正式网关：

```powershell
Invoke-RestMethod http://127.0.0.1:8080/health
```

预期返回 `status: ok`、`mode: integration` 和 `liveCommandAvailable: false`。其中最后一项是安全设计：当前浏览器只能提交任务申请，不能越过现场安全控制器控制设备。

## 3. 启动演练系统（仅测试）

在 Windows PowerShell 中执行：

```powershell
cd E:\Codex\water-embodied-command-center
npm install
npm run dev:realtime
```

浏览器打开 <http://127.0.0.1:5173>。页面右上角显示“实时网关”表示前端、网关和 SSE 实时推送已连接。

另开一个 PowerShell 窗口检查网关：

```powershell
Invoke-RestMethod http://127.0.0.1:8787/health
```

预期返回 `status: ok`、`mode: simulation`。测试结束时，在启动窗口按 `Ctrl+C` 停止服务。

## 4. 页面功能使用

### 4.1 三维地图

- 左键拖动：平移场景。
- 右键拖动：旋转、俯仰查看地形、坝体和闸门。
- 鼠标滚轮或右上角 `+ / −`：缩放。
- `正射 / 鸟瞰 / 坝体`：切换预置相机视角。
- 点击三维设备标识或左侧设备卡：选中设备，查看链路、电量、速度和位置。

### 4.2 电子围栏

1. 在“态势总览”左侧点击“电子围栏”。
2. 输入区域名称，选择“禁入区域”“限高区域”或“水面作业区”。
3. 点击“开始在地图点选”。此时地图进入绘制状态。
4. 在三维地形上依次点击至少 3 个边界点。
5. 必要时点击“撤销上一点”，确认后点击“保存区域”。
6. 保存后的围栏会在地图中显示，并保存到实时网关；可在围栏列表中删除。

正式入口把围栏保存到 `data/operator-state.json` 并同步给已打开的运营页面。真实运行前，仍必须将经过审批的围栏版本、坐标系、有效期和高度限制同步给飞控/船控/机器人安全控制器。

### 4.3 无人设备传感器监测

点击“传感监测”，选择具体设备：

| 设备 | 演练监测项 |
|---|---|
| 无人机 | 飞行高度、环境风速、云台温度 |
| 无人船 | pH、浊度、水温 |
| 轮式机器人 | 柜体温度、设备振动、可燃气体 |
| 机器狗 | 坡面倾角、表面温度、有害气体 |

传感器读数每两秒随网关遥测刷新。黄色状态表示当前读数超过演练阈值，应在“事件管理”中核验并处置。

### 4.4 告警、视频与协同任务

1. 点击右侧任一告警，进入“事件管理”。
2. 正式模式下，“查看原始帧”会检查已接入的现场视频流；未接入时会明确显示“未配置现场视频流”。
3. 点击“提交协同任务申请”，系统会在网关创建待现场审批的审计记录；不会改变真实设备执行状态。
4. 打开“协同编排”，按设备类型筛选时间线，保存草稿或发布计划。
5. 演练模式可以启动模拟任务；正式集成模式只会提交待审批计划，设备状态仍以现场遥测为准。

“实时画面”用于验证统一视频入口，“系统设置”中的“检查实时网关健康状态”用于确认服务在线。

## 5. 实验室离线测试

### 5.1 最小测试设备

- 一台运行本系统的 Windows 电脑。
- 可选：一台笔记本或工控机作为边缘适配器模拟器。
- 可选：无人机飞控模拟器、MQTT Broker、ROS 2 节点或厂商 SDK 模拟器。
- 局域网交换机；不建议在公网暴露测试网关。

### 5.2 注入模拟无人机遥测

以下命令可模拟一架无人机上报位置、飞行状态与传感器数据：

```powershell
$body = @{
  deviceId = 'UAV-D01'
  type = 'drone'
  state = '飞行中'
  battery = 73.5
  linkQuality = 96
  speed = 12.8
  location = '大坝东侧'
  x = '72%'
  y = '42%'
  protocol = 'mavlink'
  sensors = @{
    flightAltitude = 121.6
    windSpeed = 6.2
    cameraTemp = 38.1
  }
} | ConvertTo-Json -Depth 3

Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8878/api/v1/ingest/telemetry' -ContentType 'application/json' -Body $body
```

预期结果：网页中的无人机卡片、三维位置卡和“传感监测”面板在数秒内显示新数据。

### 5.3 注入模拟告警

```powershell
$alert = @{
  level = 'critical'
  title = '测试：右岸边坡位移异常'
  place = '右岸边坡 K1+080'
  confidence = '91%'
  source = 'offline-test'
} | ConvertTo-Json

Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8878/api/v1/ingest/alerts' -ContentType 'application/json' -Body $alert
```

预期结果：右侧告警列表出现新事件；点击后可以进入处置页面并提交协同任务申请。

### 5.4 接入模式测试

正式入口已经默认运行集成模式。开发环境需要停止内置数据波动、仅接收外部适配器遥测时，可使用：

```powershell
$env:GATEWAY_SIMULATION = 'false'
npm run dev:realtime
```

此模式仍拒绝真实控制指令，适合把 MAVLink、MQTT 或 ROS 2 适配器的数据接入网页进行观察。重新打开终端后该环境变量不会保留；恢复演练模式时不要设置该变量，或设为 `true`。

## 6. 封闭场地联调步骤

进行真实设备联调前，必须取得场地、飞行/航行和设备安全许可，并由具备资质的人员在现场操作。

1. **只读联调**：先启动 `integration` 模式，只上报遥测、视频和传感器，不执行控制指令。
2. **坐标校准**：确认设备经纬度、高程、航向和地图投影一致；用已知地标验证三维位置误差。
3. **围栏校验**：在网页建立测试围栏，同时在飞控/船控/机器人控制器配置相同且经审批的围栏；验证接近边界时产生告警和拒绝结果。
4. **单设备演练**：按“无人机 → 无人船 → 轮式机器人 → 机器狗”的顺序，分别验证链路中断、低电量、急停、传感器异常和回执。
5. **多设备演练**：仅在所有单设备测试通过后，测试告警触发后的协同任务编排与模拟下达。
6. **人工接管**：每轮测试确认现场急停、遥控器接管、失联策略和应急联系人可用。

严禁在未完成上述步骤时尝试通过开发电脑控制真实设备。当前标准网关会拒绝所有 `live` 请求；真实控制只能由经过安全评审和认证的现场边缘执行适配器完成，且必须验证人工审批、设备健康和电子围栏。

## 7. 验收清单

- [ ] `http://127.0.0.1:8080` 可打开，右上角显示“集成网关”。
- [ ] 已接入的设备状态、电量、链路和速度持续更新；未接入设备不显示样例数据。
- [ ] 传感器面板能切换四类设备并显示三项测点。
- [ ] 自定义围栏可以点选、撤销、保存、刷新后保留、删除。
- [ ] 三维地图可平移、旋转、缩放和切换预置视角。
- [ ] 遥测和告警注入后，页面在数秒内更新。
- [ ] 告警确认、协同任务申请、计划发布和审批状态提示均成功。
- [ ] 视频面板与网关健康检查可打开并返回结果。
- [ ] 所有真实设备测试均保留操作记录、审批记录、遥测日志和现场人员签字。

## 8. 自动化验证

在交付或每次更新后执行：

```powershell
npm run qa:realtime
npm run qa:operator
npm run test:gateway
npm run build
npm run test:sites
```

`qa:realtime` 覆盖演练闭环；`qa:operator` 验证正式入口不显示样例设备、告警或视频，并保持现场集成状态。
